A2A Order Network

Verteiltes Multi-Agent-System: Vier Agents laufen als eigene Prozesse auf eigenen Ports, finden sich über eine Agent-Registry und erstellen gemeinsam per A2A-Protokoll aus einer Kunden-E-Mail ein vollständiges Angebot. Intern nutzt der Inventory-Agent den MCP-Server aus Teil 1.

Installation

Python ≥ 3.11GitOpenAI-API-Key
  1. Repository klonen
    git clone https://github.com/ra0037I/a2a-order-network
cd a2a-order-network
  2. Umgebung anlegen und Pakete installieren
    python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

    Linux/macOS: source .venv/bin/activate

  3. Konfiguration anlegen
    copy .env.example .env

    In der .env eintragen: LLM_PROVIDER=openai und OPENAI_API_KEY=sk-…

Starten

  1. Terminal 1 – alle Dienste starten
    python run_all.py

    Startet Registry (:8000), MCP-Server (:8200) und vier Agents (:8100–8103) als eigene Prozesse. Warten bis [run_all] ready erscheint.

  2. Terminal 2 – Kunden-E-Mail senden
    python client.py --demo 1   # 1, 2, 3, all

    Der Client findet den Orchestrator über die Registry und gibt das fertige Angebot aus.

  3. Registry im Browser ansehen
    http://127.0.0.1:8000/agents
  4. Ergebnisse prüfen
    logs\client_run_*.log        # Angebot
logs\orchestrator-agent.log  # A2A

    Tests: python -m pytest -q (inkl. End-to-End-Lauf aller Prozesse)
